# Ohje Tiedostonimien Käyttöön - Taideteosten Kuvat

## Miksi Hyvät Tiedostonimet Ovat Tärkeitä?

Hyvin nimetyt kuvatiedostot auttavat:
- **Hakukoneoptimointia (SEO)** - Google löytää teoksesi paremmin
- **Organisointia** - Löydät tiedostot helpommin
- **Ammattimaista vaikutelmaa** - Verkkosivusi näyttää huolitellulta

---

## ✅ Parhaat Käytännöt

### 1. **Käytä Teoksen Nimeä Englanniksi**
Verkkosivusi on monikielinen, mutta tiedostonimet englanniksi toimivat parhaiten.

**Esimerkki:**
- Teos: "Talvimaisema"
- Tiedosto: `winter-landscape.jpg`

### 2. **Erottele Sanat Viivoilla (-)**
Älä käytä välilyöntejä tai alaviivoja.

**OIKEIN ✅**
```
winter-landscape.jpg
finnish-forest.jpg
abstract-blue.jpg
```

**VÄÄRIN ❌**
```
winter landscape.jpg  (välilyönti)
winter_landscape.jpg  (alaviiva)
winterlandscape.jpg   (ei erotinta)
```

### 3. **Vain Pienet Kirjaimet**
Käytä aina pieniä kirjaimia.

**OIKEIN ✅**
```
winter-landscape.jpg
```

**VÄÄRIN ❌**
```
Winter-Landscape.jpg
WINTER-LANDSCAPE.jpg
```

### 4. **Vältä Satunnaisia Numeroita**
Älä käytä merkityksettömiä numeroita.

**OIKEIN ✅**
```
winter-landscape.jpg
winter-landscape-2024.jpg  (vuosi on merkityksellinen)
```

**VÄÄRIN ❌**
```
winter464534654.jpg
IMG_1234.jpg
photo.jpg
```

### 5. **Useat Versiot**
Jos teoksesta on useita versioita, käytä numeroita loppuun.

**OIKEIN ✅**
```
winter-landscape-1.jpg
winter-landscape-2.jpg
winter-landscape-3.jpg
```

## ⚠️ Mitä Välttää

❌ Ääkköset: `metsä.jpg` → ✅ `forest.jpg`  
❌ Välilyönnit: `winter landscape.jpg` → ✅ `winter-landscape.jpg`  
❌ Isot kirjaimet: `Winter-Landscape.jpg` → ✅ `winter-landscape.jpg`  
❌ Erikoismerkit: `teos@2024.jpg` → ✅ `artwork-2024.jpg`  
❌ Satunnaiset numerot: `IMG_1234.jpg` → ✅ `landscape-2024.jpg`

## ✨ Nopea Muistilista

Ennen kuin lataat kuvan:

1. ✅ Onko tiedostonimi **englanniksi**?
2. ✅ Käytänkö **pieniä kirjaimia**?
3. ✅ Erotetaanko sanat **viivoilla** (-)?
4. ✅ Onko nimi **kuvaava** ja **selkeä**?
5. ✅ Vältänkö **satunnaisia numeroita**?

Jos vastasit KYLLÄ kaikkiin → Tiedostonimi on hyvä! 🎉
